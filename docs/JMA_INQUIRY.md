件名：サーフィン情報ページにおける予報業務該当性についてのご相談

気象庁 情報基盤部 情報利用推進課 御中

沖縄本島でサーフィンスクール「琉球サーフベース」を運営しております Kaito と申します（ウェブサイト制作担当：SS）。
現在、ウェブサイトとTelegramチャンネルで、利用者が自分で海況を読み解けるよう、データの提示と一般的な解説を行うページを準備しております。
当方は予報業務の許可を受けておらず、独自の予想や「おすすめ」「適否」の判断は一切掲載しない方針です。そのうえで、以下の点が予報業務に該当するかご教示いただけますでしょうか。

1. **第三者サービスの数値モデル値の表示について**
   Open-Meteo（ECMWF等の数値予報モデルを基にした第三者サービス）が提供する、特定の格子点の予測値（うねりの高さ・向き・周期、風向・風速・突風）を、当方では内挿や地形補正などの加工を行わずに、7日先までの時系列でそのまま表示することを検討しております。
   その際は「予報ではなく数値計算の結果であり、大きな誤差を含む可能性がある」ことを明示します。
   この表示は予報業務に該当しますでしょうか。

2. **潮位表のグラフ化と、ポイントの静的な解説について**
   気象庁の潮位表（那覇・沖縄）を、出典を明記したうえでグラフ化して掲載します。
   あわせて別ページで、沖縄本島の西・東・南・北の海岸ごとに「潮位が低いとリーフが浅くなる」「陸から海へ吹く風がオフショアになる」といった、日付によらない一般的な解説を掲載します（個別のサーフポイントは掲載せず、当日のデータとの自動照合・判定も行いません）。
   これは予報業務に該当しますでしょうか。

3. **インストラクターによる現況の発信について**
   インストラクターが当日朝に実際に海を見て、その時点の波の状況（観察結果）をTelegramに投稿し、サイトにも表示します。
   現況の観察結果の発信であり、予報業務には該当しないという理解でよろしいでしょうか。

4. **府県天気予報の翻訳転載について**
   気象庁の府県天気予報（天気・風・波）および週間天気予報を、出典と翻訳・加工の旨を明記したうえで、原文と中国語・英語訳を併記して転載することに問題はありますでしょうか。
